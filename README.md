# RentX 🚗

A car rental web application where owners list their vehicles and customers browse and book them online.

## 🚀 Live App

Check out the live site: https://rentx-pggo.onrender.com


## 📝 About

RentX is a Django web application for car rental. Owners can list their cars with photos and prices, and customers can browse available vehicles and book them for chosen dates. The system checks availability automatically, so the same car cannot be booked twice for overlapping dates.

## ✨ Features

- User registration and login
- Browse available cars
- List a car for rent (become a host) with photo upload
- Book a car for selected dates
- Automatic check to prevent double bookings
- Owners can manage bookings on their listings
- Responsive design that works on mobile and desktop

## 🛠️ Tech Stack

- **Backend:** Python, Django
- **Database:** PostgreSQL (SQLite for local development)
- **Image storage:** Cloudinary
- **Server:** Gunicorn, WhiteNoise
- **Hosting:** Render
